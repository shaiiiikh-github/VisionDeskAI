# VisionDesk AI

VisionDesk AI is a desktop assistant inspired by Copilot Vision.

## Features

- Screen Understanding
- AI Overlay
- Gemini Vision
- OCR
- Voice Commands
- Global Hotkeys

## Tech Stack

Frontend:
- React
- Electron
- Tailwind CSS

Backend:
- FastAPI
- Python

AI:
- Gemini 2.5 Flash
